# 49 - Focus Booster

The website for **49 - Focus Booster**, a Schulte table game for iPhone and Android: find the numbers 1 to 49 in order, as fast as you can.

**Website:** https://49game.github.io/

49 is out now, free on the [App Store](https://apps.apple.com/app/id6823997426) for iPhone. On Android it is in testing on Google Play, and anyone can join: [how to join](https://49game.github.io/#android).
